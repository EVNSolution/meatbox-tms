# 배송원 프로필 후보

> **이력·검토 자료.** 아래 내용은 작성 당시의 계획·판정·시험 결과입니다. 수량·구현 상태·배포 여부를 현재 상태로 해석하지 않습니다. 현행 계약과 절차는 [문서 안내](README.md), 후속 전환 조건은 [운영 전환 기준](production-readiness.md)을 사용합니다.

상태: 2026-09-15 사용자 요청에 따른 **미배정 후보**. 실제 데이터 수신 후 별도 예시 프로필을 연결한다. 아래 항목은 현재 배송원에 부여된 평가나 권역이 아니다.

## 표시 후보

| 후보 | 필요한 근거 | 데이터 수신 전 |
|---|---|---|
| 냉장 보관 요청 경험 | 배송원 ID에 연결된 요청 종류와 이행 기록 | 성향 미등록 |
| 대면 인계 경험 | 직접 전달 요청과 확인 기록 | 성향 미등록 |
| 매장 출입 정보 숙지 | 검수된 배송지 팁과 실제 배정 기록 | 성향 미등록 |
| 선호 전달 방식 | 배송원 본인이 제공한 프로필 | 성향 미등록 |
| 메인 권역 | 운영자가 지정한 권역 ID·이름과 배송원 ID | 메인 권역 미등록 |

경험이나 선호를 자동으로 우수/보통/미흡 등급으로 바꾸지 않는다. 예시 프로필을 적용할 때는 예시 표식을 붙이고, 기존 배정과 성과 계산에 영향을 주지 않는다. 폴리곤, 핀배차, 지원배차 점수의 입력으로 사용하지 않는다.

## 연결 전 필요한 필드

- 배송원 고유 ID: 이름이 같은 배송원을 합치지 않는다. 현재 차량 ID는 배정 단위 지표의 연결 키이며 영구 배송원 ID를 대신하지 않는다.
- 프로필 출처와 갱신 시각: 실제/예시 구분, 검수 여부, 적용 기간.
- 성향 항목: 항목 ID, 표시명, 근거 또는 본인 제공 여부. 미수신과 명시적 항목 없음 구분.
- 메인 권역: 확인된 권역 ID와 표시명. 실제 경계가 오기 전에는 지도 경계·내부 집계·편집을 제공하지 않는다.
- 배송지 팁: 배송지 ID에 연결된 검수된 내용. 고객 요청과 구분한다.

## 현재 제공하는 지표

자원 관리의 배정·완료·잔여·보류 배송지와 박스 수는 현재 배정 데이터에서 계산한다. 배송지 수는 배송 ID 기준이며, 보류 배송은 잔여에 포함한다. 박스 수가 누락된 집계는 미등록으로 표시한다. 이 지표는 영구 근무 이력이나 개인 평점이 아니다.
