전체 회귀는 이 작업 공간에서 `npm test`(`node --test`)로 실행했다. 이미 설치되어 있고 잠금 파일 버전과 일치하는 의존성(express `4.22.2`, ws `8.21.3`)을 임시 `node_modules` 심볼릭 링크로 사용하고 종료 후 제거했다. `npm ci`를 새로 수행한 검증은 아니다. `pipefail` 셸에서 성공 완료했으며 도구 출력의 결과는 아래와 같다. 전체 원시 로그 파일은 별도로 보존하지 않았다. 의존성 링크 제거 뒤 독립 검토에서 시도한 추가 API 테스트 3개는 모듈 로딩 단계에서 실행되지 않았다. 이는 위 의존성을 갖춘 전체 회귀 결과와 구분하며, 재실행자는 개발 문서의 의존성 설치를 먼저 수행해야 한다.

로컬 시작 검증은 문서의 관리 CLI와 `server.js`를 사용했다. 초대 발급 후 가입 303, 로그인 화면 200, 익명 루트 302, 익명 세션 401, 로그인 303, 인증 세션 200, 합본 정적 화면 200, 미설치 manifest 404, 미설정 자원 503, 계정 비활성화 CLI 성공, 다음 세션 요청 401을 확인했다. 테스트 프로세스를 종료하고 임시 계정·파일을 제거했다. 실제 브라우저 렌더링이나 고객·배송원 기기 검증은 아니다.

교차 검토에서 보강한 사항은 자원 v1의 `unchanged` 출력 전 스키마 변경 가능성, 백업의 서비스 중지 조건, 코드 롤백과 시점 복원의 분리, 비활성 계정의 다음 요청 적용, 예시 사진의 출처, 날짜 API 예제와 필수 요청 ID의 의미다. 날짜 파일명과 본문 날짜의 서버 직접 대조 공백도 운영 전환 과제로 기록했다.
