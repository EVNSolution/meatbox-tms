## 내용이 없거나 대기 중인 항목

- **고객 요청:** 실제 주문 경로의 `customerRequests`가 null이다. 이번 배송의 카메라 후 확인 화면에는 `정보 미수신`만 나오고 냉장고/문 앞/실내 요청 아이콘 및 요청별 필수 체크를 시연할 수 없다. 요청 UI 자체와 해당 주문의 요청 데이터 연결을 구분해야 한다.
- **상품/운송:** 상품 상세는 비어 있다. 운송 조건은 공통 기본값 `보냉 운송 / 포장 상태 확인`으로 표시된다. 개별 상품의 냉장/냉동 구분·온도·품목은 제공 자료에 없다.
- **배송지 이름/팁:** 일부 배송지 이름은 `1`, `1층`, `지층`처럼 상호가 식별되지 않는다. 확인한 배송지의 팁도 미등록이다. 임의 상호/팁을 사실처럼 채우면 안 된다.
- **배송원 프로필:** 성향·메인 권역은 미등록. 실제 배정·완료·잔여·보류 수량 지표는 갱신되지만 배송지 단위 문제(A37-4)가 있다.
- **근무 시간:** 과거 날짜의 물량은 조회되지만 출근/퇴근·운행 시작/종료 시각은 자료에 없어 표시되지 않는다.
- **지원배차:** 완료 수량만 보이고 예상 완료/속도는 미확인·산정 대기다. GPS, 등급 경계, 호출/수락/재배정 연결이 없어 호출·지원 지시는 비활성이다. 기준 미정은 기존 합의사항이다.
- **실차 정보/영구 저장:** 이름은 기록 기반이지만 차량번호·차량 위치는 표시용 값이다. 외부 기사 수신/수락과 배차·사진의 영구 저장은 연결되지 않았다.
