# 헤더·운영일 정리 계획 (2026-09-27)

상태: 지정 범위의 로컬 구현·검증 완료. 격리 릴리스 후보에는 B_AREA DB/API 작업을 포함하지 않았다. 배포·커밋·운영 데이터 수정은 하지 않았다.

## 변경 범위

1. 공통 헤더의 `운영일` 선택기와 `운영/고객/배송원 뷰어` 전환을 제거한다. 데스크톱과 모바일의 반응형 헤더를 한 줄로 정리한다. 운영자 전용 내비게이션과 역할에 맞는 고객·배송원 배송 화면 직행 링크는 보존한다.
2. 배차 날짜 선택은 배차 관리 화면 안에만 둔다. 배송 관제에는 조회 날짜와 이력 탐색을 위한 화면 맥락상의 컨트롤을 둔다. 자원 관리의 기본 내비게이션에는 날짜 선택기를 두지 않는다.
3. 기본 운영일은 실제 `Asia/Seoul` 달력 날짜에서 계산한다. 발표용 manifest의 기준일이나 오래된 데모 날짜를 오늘로 대체하지 않는다. 날짜에 데이터가 없으면 비어 있음을 사실대로 표시한다. 사용자가 명시적으로 조회한 과거 날짜는 읽을 수 있지만 변경 명령은 막는다.
4. 저장된 편집 초안과 발행된 배차 checkpoint는 자정 경과와 서버 재시작 뒤에도 해당 날짜·출처·주체에 그대로 연결한다. 복원 시 identity/source 레코드가 누락되거나 형식이 잘못되면 거부하고 명확한 오류를 표시한다. 기존 운영 확정 자료와 production 파일은 재작성하지 않는다.
5. 베타의 요일별 평균은 실제 날짜 데이터와 별개 개념으로 남긴다. 이 정리에서는 베타 화면이나 새 B_AREA 전체 UI를 만들지 않는다.

## 작업·검증 순서

1. 코드 변경 전에 데이터 기반 shell 링크와 화면별 날짜 흐름, checkpoint 복원 및 자정 넘김·재시작 동작을 고정하는 회귀 테스트를 작성한다. 잘못된 identity/source 입력 거부와 과거 날짜의 읽기 전용 동작도 확인한다.
2. 기존 패턴을 사용해 헤더와 페이지별 날짜 동작을 최소 범위로 수정한다. 의존성을 추가하지 않는다. 다른 감사 대상인 데모 사진·차량 자료 등의 교체는 별도 작업으로 남긴다.
3. 변경 대상 테스트를 먼저 실행하고, 이어서 전체 Node 테스트를 순차 실행한다. 데스크톱과 모바일 브라우저에서 한 줄 헤더, 역할별 이동 링크, 날짜 선택, 빈 날짜 표시와 과거 날짜 읽기 전용 상태를 확인한다. 결과가 확인되기 전에는 완료로 표기하지 않는다.

## 로컬 완료 증거

- 전체 Node 테스트 `npm test -- --test-concurrency=1`: 451/451 통과, 실패 0건, 12.6초. 기록: `.runtime/header-date-qa/node-tests-final.log`. `git diff --check` 및 변경 Node 모듈의 `node --check`도 통과했다.
- 소스 모드 임시 fixture의 브라우저 확인(포트 3067, 시험 전용): 2026-09-16 발행 배차와 09-26 이력은 존재하고, 실제 오늘 09-27은 비어 있다. 공통 헤더에 날짜·뷰어 전환이 없고 높이 56px의 한 줄이다. 배차에는 화면 내부 날짜 선택기만 있고 시나리오 실행 버튼은 없다. 관제의 빈 오늘 → 달력의 과거 읽기 전용 조회 → 오늘 빈 상태 복귀와 잘못된 날짜 입력 후 오늘 복구를 확인했다. 자원 관리는 보이는 날짜 선택기 없이 빈 상태를 표시했다. 고객·배송원 직행 링크는 공통 컨트롤 없이 열렸고 빈 날짜를 알렸다. 과거 고객 화면은 날짜와 읽기 전용 표기를, 배송원 화면은 `배차 조회`를 보였다. 명시적 `QA-OLD-O1` 관제 링크도 유지됐다. 확인한 흐름의 콘솔 오류는 0건이다.
- 데스크톱 1440px와 모바일 390px에서 확인했다. 모바일 `scrollWidth`는 390px, 헤더 높이는 56px이다. 화면 기록: `.runtime/header-date-qa/screenshots/dispatch-desktop.png`, `dispatch-mobile.png`, `control-mobile.png`. 루트 담당자의 지정 범위 시각 판정은 PASS이며, 앱 전체에 대한 판정은 아니다.

기존 데모 사진·차량·시나리오 패널 등 다른 감사 항목의 교체와 새 B_AREA 전체 UI 연결은 범위 밖으로 남아 있다.
