# 레퍼런스의 메뉴·뷰어 구성

> **초기 디자인·정적 데모 이력.** 이 문서는 현재 구현·운영 서버의 상태를 나타내지 않습니다. [현행 저장소 문서](../../../README.md)를 먼저 사용하세요. 원문은 당시 판단의 근거로 보존합니다.

상태: **사용자 지정 배포 기준 반영** · 2026-09-14. 상단 3축과 좌측 3축을 구분합니다. 이전 `배송 현황 / 단말 관제 / 고객 보기` 좌측 구성은 대체되었습니다. 실제 배포 변경은 이번 로컬 레퍼런스 작업에 포함하지 않습니다.

## 상단: 보는 사람 선택

| 상단 탭 | 의미 | 로컬 이동 |
|---|---|---|
| 운영 뷰어 | 운영 담당자의 주문·배송 업무 | 마지막으로 본 주문 관리·배송 목록·배송 관제 |
| 고객 뷰어 | 선택 배송의 고객 노출 정보 | `#/customer` |
| 배송원 뷰어 | 선택 차량·배송의 작업 정보 | `#/driver` |

## 좌측: 운영 업무 선택

| 좌측 메뉴 | 역할 | 로컬 이동 |
|---|---|---|
| 주문 관리 | 주문 목록과 배송 연결 확인 자리 | `#/orders` |
| 배송 목록 | 검색·상태 필터·배송 선택 | `#/deliveries` |
| 배송 관제 | 진행 상태·ETA·사건·알림·관리 | `#/control` |
| 하단·검토용 디자인 가이드 | 동일한 메뉴 계약과 공식 브랜드·UI 요소 비교 | `#/design` |

좌측 업무 메뉴를 선택하면 해당 운영 뷰어로 돌아옵니다. 고객 뷰어와 배송원 뷰어는 좌측 업무 메뉴와 같은 축에 놓지 않습니다. 디자인 가이드는 세 업무 메뉴와 구분되는 하단 검토 도구입니다.

## 배송 관제 내부

- 가운데 상세 탭: **사건 이력 / 알림 미리보기**.
- 우측 탭: **배송 관리 / 장치 표시**.
- 배송 관리를 독립 메뉴로 두지 않고 관제 우측에 흡수합니다. 선택 배송의 차량·단말·상태·완료·수신 정보를 이곳에서 확인합니다.
- 장치 표시는 기존 차량 장착형 TMS 표본입니다. 배송원 뷰어와 같은 화면으로 취급하지 않습니다.

## 동작과 범위

1. 뷰어·업무 메뉴 전환은 선택 배송·시나리오·필터를 유지합니다. 운영 뷰어 복귀 시 마지막 운영 업무 페이지를 복원합니다.
2. 브라우저 뒤로/앞으로와 직접 링크에서도 상단 선택·좌측 선택·본문이 일치합니다.
3. 관제 가운데와 우측 탭은 독립 선택 상태를 갖고 방향키·Home·End로 이동합니다.
4. 주문 데이터는 연결 전이므로 주문 목록은 명시적인 빈 상태를 표시합니다. 임의 주문을 실제 주문처럼 만들지 않습니다.
5. 배송원 뷰어는 기존 합성 배송 결과를 사용한 작업 정보 표본입니다. 실제 배송 완료 처리나 배송원 장치/API 연결은 구현하지 않습니다.
6. 시나리오 팝업은 주문 관리·디자인 가이드에서 숨기고 나머지 표본 화면에서 유지합니다.
7. 검증은 이 로컬 정적 레퍼런스를 대상으로 합니다. 배포 서비스의 구현 상태와 구분합니다.
