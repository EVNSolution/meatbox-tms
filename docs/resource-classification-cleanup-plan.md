# 자원 등록부 분류 전환

> 2026-09-27 릴리스 후보 계약입니다. 이 문서는 운영 반영 전 상태이며, 실제 운영 DB 이관·서비스 전환·브라우저 검증은 별도 단계입니다.

## 범위와 자료 경계

2026-09-16 기존 날짜 자료의 차량 그룹 155개 ID와 표시 차량번호를 별도 SQLite 자원 등록부에 보존합니다. 괄호 안에 ASCII 영문자로 시작하고 뒤에 영문자·숫자만 있는 코드가 있으며 `용차`가 아닌 31개를 활성 목록에 표시합니다. 한글 혼합 코드·한글 표기·용차 등 나머지 124개도 삭제하지 않고 DB에 보존합니다. 표시 차량번호와 코드는 과거 데모 자료에서 온 값이며 실제 차량이나 직원 신원의 확인 결과가 아닙니다.

코드는 직원 식별자가 아니라 여러 차량이 공유할 수 있는 권역/그룹 카테고리입니다. 차량 행에는 등록된 지역코드 선택기와 미지정 선택지만 둡니다. 코드 추가·이름 변경은 같은 자원관리 페이지의 `지역코드 관리`에서 처리합니다. 저장은 revision 확인과 단일 트랜잭션으로 이루어지며, 잘못된 코드·비활성 차량·충돌이 있으면 일부만 저장하지 않습니다.

등록부에는 주문, 배송지, 박스 수, 위치, 운행 상태, 배차 이력을 복사하지 않습니다. 원본 날짜 JSON, 기존 배차 체크포인트, 계정 파일과 B_AREA 주문·배송 자료는 이 전환에서 수정하지 않습니다. B_AREA 모드·스토어·API 변경 및 배차 알고리즘 변경은 이번 릴리스에 포함하지 않습니다.

## 준비와 검증

운영 서비스는 `RESOURCE_DATABASE`가 가리키는 별도 영속 DB만 엽니다. 값이 없거나 DB가 준비되지 않으면 자원 API는 503으로 닫히고 과거 데모 자료로 자동 대체하지 않습니다. 신규 DB 생성은 `node scripts/import-resource-catalog.mjs --day /absolute/day.json --output /absolute/resources.sqlite`의 명시적 실행에만 둡니다. 같은 원본 지문의 재실행은 멱등이며 다른 원본으로 이미 있는 DB를 덮어쓰지 않습니다. 기존 v1 DB는 같은 출처 확인 후 v2로 이행하고, 차량·코드·revision·출처 메타데이터를 보존합니다. 배포 순서와 백업·롤백은 [운영 문서](operations.md)를 따릅니다.

이 릴리스 후보 `codex/resource-region-release`에서 Node 22.22.1 전체 테스트 450/450, 자원 API·클라이언트·화면 대상 테스트 23/23, 변경 JavaScript 문법 검사와 `git diff --check`가 통과했습니다. 이는 로컬 코드 검증이며 운영 DB 생성·서비스 전환·실제 브라우저 확인의 증거는 아닙니다.
