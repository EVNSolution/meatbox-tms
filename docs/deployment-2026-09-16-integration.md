- 기존 서버는 메모리에만 상태를 보관했다. `/var/lib/meatbox-demo/dispatch-state`를 서비스 소유 `0700`, 날짜별 체크포인트를 `0600`으로 설치하고 systemd drop-in으로 연결했다.
