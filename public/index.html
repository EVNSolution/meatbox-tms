시연 가이드 (권장 순서)

  1. 관제센터에서 ▶ 시나리오 시작 — MFC 출고 스캔이 순차 진행되고 차량이 출발합니다.
  2. 고객 앱에서 상태 타임라인이 자동으로 넘어가고 "N번째 순서 배송 예정"과 ETA 범위가 표시되는 것을 확인.
  3. 기사 앱에서 정차지 순서를 ▲▼로 변경 → 고객 ETA가 즉시 재계산됩니다.
  4. 관제센터에서 🚨 교통사고 주입 → ETA가 지연되고 고객에게 "배송 예정 시간이 변경되었습니다" 알림 발송.
  5. 배송이 진행될수록 ETA 범위가 ±20분 → ±10분 → ±5분으로 좁아지는 것을 강조 (모델 고도화 컨셉).
  6. 도착 → 인근 배송 중 → 하차 스캔 → 배송 완료 알림까지 확인.
