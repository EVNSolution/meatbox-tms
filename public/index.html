시연 가이드 (권장 순서)

  1. 고객 앱에서 🛒 주문하기 — 주문 접수·결제 완료가 기록되고 알림이 발송됩니다.
  2. 발표 리모컨에서 ▶ 다음 단계를 눌러 주문 상태를 한 단계씩 진행 (피킹 → 라벨 부착 → 상차 대기 → 배송 출발).
  3. 단계를 진행할 때마다 고객 앱과 관제 화면이 즉시 업데이트. 배송 출발 후엔 차량이 자동 주행하며 "배송 중" 상태와 도착 예정 시간이 표시됩니다.
  4. 기사 앱에서 정차지 순서를 ▲▼로 변경 → 고객 ETA가 즉시 재계산됩니다.
  5. 발표 리모컨에서 🚨 교통사고 주입 → ETA가 지연되고 고객에게 "배송 예정 시간이 변경되었습니다" 알림 발송.
  6. 배송이 진행될수록 도착 예정 시간이 계속 보정되는 것(다이나믹 ETA)을 강조.
  7. 도착 → 인근 배송 중 → 하차 스캔 → 배송 완료 알림까지 확인.
