# Customer map

The customer vehicle marker uses `dsv-vehicle-marker.svg`, copied from `clever-dsv-web/public/map/vehicle-marker-default.svg` with explicit SVG filter coordinates, the runtime white outline, and the requested bright lime fill `#BEF264`. The customer store marker ports the house path from `src/components/DepartureMarker.ts` and its 26 × 34px green pin styling from `src/styles/components/map.css`. Both customer markers have accessible names without visible captions.

The order-management destination marker is an SVG port of `clever-dsv-web/src/components/map/DestinationMarkers.ts`: restyled as a Kakao-map style droplet: Meatbox red `#e60028` body, white outline and inner dot, soft shadow, 0.62 display scale (24.8 × 32.24px). Existing coordinates and order selection behavior remain in their respective viewers.

The `dsv-korea-v1.json` style is copied unchanged from `04_CLEVER_Route/clever-dsv-web/public/map/styles/dsv-korea-v1.json` (profile `dsv-korea-v1`, version `2026-07`). It uses OpenFreeMap tiles, sprites and glyphs from `tiles.openfreemap.org`. The demo route uses the existing OSRM geometry in `workspaces/sanghyun-scenario/src/route-data.js`, generated by its `scripts/gen-routes.mjs`. The example truck starts on a stable intermediate road coordinate and follows the stored remaining geometry. No straight connector or live GPS is used; the browser does not call a routing provider.

The sibling `vendor/maplibre` directory contains MapLibre GL JS 5.24.0 CSP browser and worker bundles, CSS and its license, copied from the same project's installed package. The worker is served from this authenticated origin. No CDN script or npm dependency is added.

The DSV application map setup is in `clever-dsv-web/src/components/MapCanvas.tsx`; it uses MapLibre's default wheel interaction. Meatbox adds a Control-or-Command wheel gate to dispatch and control maps in `map-wheel-zoom.mjs`, reusing the copied MapLibre CSS classes and animation for the instruction screen. Customer and driver phone maps use the default wheel interaction without that screen. Driver route editing still locks zoom. Touch interaction is unchanged.
