로그인 후 시연 안내에서 시작하고, 헤더에서 **운영 뷰어 · 고객 뷰어 · 배송원 뷰어**를 전환하는 데모입니다. 운영 업무는 왼쪽의 **주문 관리 · 배송 목록 · 배송 관제**로 나눕니다. 이번 다차량 작업은 주문 배차 지도, 차량 130대와 배송지 395곳의 얇은 목록, 선택 배송 관제, 고객 알림과 배송팁을 검토합니다. 실제 주문 좌표, 권역 경계, 배차 알고리즘과 외부 고객 알림 발송은 연결하지 않습니다. 현재 화면 구성 기준은 [DESIGN.md](DESIGN.md), 구현 계약은 [다차량 운영 계획](docs/fleet-operations-plan.md)에 있습니다.

`workspaces/`의 두 원본은 보존용입니다. 박상현 원본 기준 커밋은 `f41af790be7529d4d2da9e8ac44826acdd120a50`이며, 원본 파일별 SHA-256은 `docs/source-snapshots.json`에 있습니다. 원본 코드 수정은 별도 작업으로 검토하고, 통합 변경은 `apps/combined/`와 루트 게이트웨이에 적용합니다. `/scenario/` 경로와 WebSocket 주소만 HTTP 응답 시 치환하여 원본 바이트를 유지합니다.

시나리오와 합본은 **하나의 메모리 시뮬레이션**을 공유합니다. 어느 화면에서든 단계 변경/리셋하면 접속한 모든 검토자에게 반영됩니다. 서비스 재시작 시 시뮬레이션과 로그인 세션은 초기화되고 계정은 유지됩니다. UI/레이아웃은 독립 표본입니다.

다차량 표본은 차량 130대와 배송지 395곳, 7,800박스를 표현합니다. 이 가운데 차량 V1의 배송지 8곳과 60박스만 기존 원본 시뮬레이션과 직접 상호작용합니다. V2부터 V130까지는 차량별 20박스 배송지 3곳을 둔 화면 검토용 표본이며, 확인되지 않은 주소와 ETA를 만들어 내지 않습니다. `customer?id=S5`는 시연 배송 선택이며 로그인 권한을 대신하지 않습니다.

주문 관리는 지도를 사용하는 유일한 합본 운영 페이지입니다. 선택 차량의 주문을 빈 지도 배경 위 예시 위치 기호로 나열하고, 위치가 실제 좌표나 배차 결과가 아님을 표시합니다. 배송량은 0부터 7,800박스까지 선택하며 차량당 60박스로 필요한 차량 수를 단순 계산합니다. 권역 경계, 실제 좌표와 배차 알고리즘은 후속 데이터 계약에서 교체합니다.

세 뷰어의 공통 **플로팅 시연 가이드**에서 현재 단계, 시연 시각, 다음 단계의 시각과 바뀔 내용을 확인할 수 있습니다. 주문 접수 → 피킹 → 라벨 부착 → 상차 대기 → 배송 출발을 진행한 뒤, **도착까지 시간 진행 → 배송 완료 처리**로 첫 배송지부터 마지막 배송지까지 시연합니다. 도착은 기존 이동·교통 계산을 거치며, 완료 처리는 도착 후 현재 시각으로 하차 완료 스캔을 기록합니다. 펼친 패널은 가로로 길게 표시하고 왼쪽 핸들로 이동합니다. 접으면 174×42px의 작은 시연 가이드 버튼만 남습니다. 뷰어를 바꾸어도 위치와 펼침 상태를 유지합니다. 배속·초기화와 단계별 설명은 상세 설정에서 사용합니다. 자동 주행·자동 하차 완료와 배속도 계속 사용할 수 있습니다.

배송 목록은 전체 395곳을 데스크톱 기준 44px의 얇은 한 줄 행으로 표시합니다. 차량, 상태, 배송지, 주소와 배송원으로 찾고, 선택 카드에서 상세와 배송원이 작성한 배송팁을 확인합니다. 실시간 갱신이나 필터가 명시적으로 고른 배송을 임의로 V1으로 바꾸지 않습니다.

배송 관제는 선택 배송의 운영 정확 ETA, 고객 안내 시간대, 실제 도착, 배송 완료, 타임라인과 사건 이력을 우선 표시합니다. 장치 표시와 지도는 배송 관제에서 제거합니다. 우측 배송지 목록은 선택 배송과 같은 차량의 배송지만 보여 주고, 같은 배송지 상세를 반복하지 않습니다. 배송 순서 편집은 실시간 V1의 8곳에만 적용합니다.

배송 관제 우측 **배송 관리** 탭에서는 **순서 편집 → 손잡이 또는 위아래 버튼으로 이동 → 변경 저장 / 취소**로 작업합니다. 저장 전에는 다른 화면에 반영되지 않습니다. 배송 중·완료·보류 행은 고정하며, 편집 중 실제 순서나 배송 상태가 달라지면 최신 상태에서 다시 편집하도록 안내합니다. 서버도 기대한 순서·상태와 현재 값을 비교한 후 전체 순서와 ETA를 한 번에 반영합니다. 보류·복원은 편집 모드 밖에서 개별 배송에 적용하며, 시연 주문 고객은 원본 정책대로 보류할 수 없습니다.

시연의 **고객 뷰어**는 상현님 고객 시나리오의 주문·ETA·지도·배송 타임라인·알림을 사용하는 별도 페이지입니다. 운영 뷰어는 계속 계산되는 정확 ETA를 보여 주고, 고객 뷰어는 약속 ETA 앞뒤 30분의 시간대를 보여 줍니다. 정확 ETA가 현재 고객 약속 기준보다 늦게 30분을 초과하면 시간대를 갱신하고 지연 알림을 한 번 추가합니다. 문서의 `실제 도착 대비 ±15분 이내 80% 이상`은 정확도 목표이며 고객 시간대나 알림 임계값이 아닙니다.

`mobile-customer.html`과 `mobile-customer.css`가 고객 화면을 구성하고, 인증된 상태 연결을 재사용합니다. 현재 고객을 대상으로 새 알림 ID가 들어오면 한 번만 팝업으로 보여 주며 최초 이력이나 서버 재시작 뒤 초기 이력을 다시 팝업으로 재생하지 않습니다. 768px 미만에서는 프레임 없이 화면 너비에 맞춘 한 열을 사용합니다. 큰 화면에서는 왼쪽 390px 모바일 뷰어와 오른쪽 배송 타임라인을 함께 확인합니다. `?id=S5`로 특정 매장을 바로 열 수 있으며 실제 결제나 알림 발송은 하지 않습니다.

배송 관제 본문의 **고객 알림** 탭은 시각, 대상, 제목과 내용을 보여 줍니다. 운영자는 선택 배송에 최대 300자의 안내 문구를 팝업으로 확인한 뒤 시연 기록으로 추가할 수 있습니다. 알림 로그는 정차지별 최근 50건, 전체 최근 1,000건까지만 보존하므로 오래된 항목은 화면 범위를 벗어납니다. **배송원 뷰어**는 선택 배송의 차량 문맥을 따르고 배송지별 최대 500자의 배송팁을 편집합니다. 서버 상태에서 저장을 확인한 뒤 다른 뷰어에 같은 값을 반영하며, 합성 차량에서는 V1 배송 완료 동작을 열지 않습니다. 사고와 정차 지연을 직접 발생시키는 버튼은 합본에서 제거하지만 원본 계산 알고리즘은 유지합니다.

시연 가이드 안에서 **차량 진행**과 **선택 배송**을 구분합니다. 시연 주문 고객 S5와 현재 목적지의 관계, 앞선 미완료 배송 수를 실제 순서로 안내합니다. 상세 설정의 **최근 변동**은 이 페이지를 연 뒤 수신한 단계·고객 상태·공식 ETA·도착/완료 시각·알림의 전후 값이며, 단순 시계 진행과 계속 계산되는 ETA는 제외합니다. 초기화하면 비교 기록도 비웁니다. 헤더로 뷰어를 전환할 때 같은 `id`로 선택 배송과 주문·배송 조회 조건을 유지하고, 운영 뷰어로 돌아오면 마지막 업무 페이지를 복원합니다. 고객 뷰어에서 매장을 바꾸고 운영 뷰어로 돌아와도 그 배송을 유지합니다. 고객 렌더러와 시연 가이드는 페이지당 하나의 인증된 상태 연결을 공유합니다. 원본 시뮬레이션과 주문·ETA·지도 동작은 그대로 재사용합니다.

공식 미트박스 로고·앱 아이콘과 Pretendard Variable은 `apps/combined/assets/`에 보관합니다. 원본 URL·해시·폰트 라이선스는 `assets/SOURCES.md`와 `assets/OFL-1.1.txt`에서 확인합니다. 좌측 탭은 오른쪽 3px 직선, 상단 탭은 하단 3px 직선으로 강조하며 좌측 그림자나 두꺼운 좌측 강조선은 사용하지 않습니다.

## 로컬 실행

Node.js 22 이상을 사용합니다. 별도 번들 빌드 없이 Express와 ws만 설치합니다.

```sh
npm ci
mkdir -p .runtime
node scripts/manage-access.js issue-invite --file .runtime/access.json --output .runtime/invite.txt
PUBLIC_ORIGIN=http://127.0.0.1:3001 ACCESS_FILE=.runtime/access.json PORT=3001 npm start
```

`http://127.0.0.1:3001/dev/register`에서 초대 파일의 코드를 입력하여 가입한 뒤 로그인합니다. 초대 코드는 기본 24시간 내 1회 사용 가능하며 회원가입 링크는 일반 화면에 노출하지 않습니다. 기본 계정/비밀번호는 없습니다.

```sh
npm test
node --check server.js
node --check lib/access.js
node --check apps/combined/app.mjs
git diff --check
```

인증, 익명 HTTP/API/WebSocket 차단, 외부 Origin 거부, 세션 종료, 초대 1회 사용, 원본 보존, ETA 의미와 UI 팝업 범위를 검증합니다. 다차량 수량, 30분 초과 경계, 고객 알림과 배송팁의 교차 뷰 동작은 [테스트 명세](docs/fleet-operations-test-spec.md)를 따릅니다. CSS는 실제 브라우저에서 320px, 390px와 1280px를 함께 점검합니다.
